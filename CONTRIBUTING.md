## I Have a Question

Before you ask a question, please check through the [issues](https://github.com/yoinc-development/cleard/issues), maybe you can find the answer there.

If you still have a question, you can open a ticket with the issue "question".

## I Want To Contribute

You may contribute in any form you want. If you want to take over a task, just leave a comment and it will be assigned to you. Create a pull request associated with 
the associated issue and it will be looked at in a timely manner. 

## General Suggestion / Bug Report Etiquette

Depending on the issue type there is a template for all relevant fields and attributes required. When submitting an issue, please make sure to 
fill them all out. Issues missing relevant data will be closed.

## Commit Messages

A commit message should contain the type of issue, a general commit message and the issue number. 

Feature
> feat: commit message #1 

Bug
> bug: commit message #1
